# 📱 App de Cadastro Flutter

## 🎯 Objetivo

Aplicativo desenvolvido para demonstrar um formulário completo de cadastro com validações, UX moderna e boas práticas em Flutter.

---

## 🚀 Funcionalidades

✅ Formulário com validação completa
✅ 8 campos obrigatórios
✅ Máscaras (CPF, telefone, data)
✅ Validação de senha
✅ Confirmação de senha
✅ Validação assíncrona de email
✅ Checkbox obrigatório (termos)
✅ Feedback com SnackBar
✅ Loading durante envio
✅ Layout moderno com gradiente

---

## 🎨 Interface

* Tema moderno com cor roxa
* Fundo com gradiente
* Card central com sombra
* Ícones nos campos
* Experiência semelhante a apps reais

---

## 🧠 Tecnologias

* Flutter
* Dart
* mask_text_input_formatter

---

```bash
flutter pub get
flutter run
```
